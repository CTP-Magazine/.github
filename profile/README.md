## How it works

The magazine is a re-syndicating engine. It pulls from 114 verified RSS feeds, every one vetted live and cleared for what the magazine may republish before it goes on the list, and pushes their articles into the portal. Articles refresh every 12 hours, and every item carries its attribution and a link back to the original.

* GitHub Pages serves the site.
* GitHub Actions runs the aggregator every 12 hours and writes `articles.json`.
* The magazine page reads `articles.json` and renders article cards.

No Vercel backend, no database. GitHub Actions plus GitHub Pages only.

The clearance gate is absolute. No uncleared feed ever goes on the list. Hero and thumbnail images come only from the cleared image pool, NASA public domain and ESO CC BY 4.0 and author-owned CC BY sources, never from wire services or named photographers.

## Syndicate with us

Many bloggers on Substack, Blogger and elsewhere get little traffic, because nobody follows a one-off single blog. CTP Magazine syndicates blogs like yours and pushes the articles into the portal, in front of the magazine's readers: an excerpt plus a prominent link back to your original, with attribution on every item.

There is no open submission form. Syndication is set up by contact: email syndication@ctp-energy.com and the magazine will set it up with you. Every feed is vetted by the magazine first, before it is added.
